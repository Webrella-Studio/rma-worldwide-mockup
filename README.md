# RMA Worldwide Website Concept

A responsive homepage redesign concept for RMA Worldwide Chauffeured Transportation, created by Webrella Studio.

## Concept goals

- Make booking the primary user journey
- Present RMA as a polished global transportation brand
- Clarify services and fleet options
- Build trust through scale, support, and service standards
- Create a fast, responsive experience for desktop and mobile

## Run locally

Open `index.html` in a browser or run a static server from the project folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Note

This is an independent design concept for presentation purposes. The hero artwork is original and contains no third-party branding.
